05 / Diagnose by Gates

「見つからない」を6段階へ分ける

最終Finding数だけではmodel能力とharness欠陥を区別できない。各gateの入力と出力を独立に観測する。

1. Target Identity本当にvulnerableなsource digestか
2. Map Coverage入口・sink・state anchorがMapにあるか
3. Focus Rank最初の3 Leaseへ重要surfaceが入ったか
4. Context Reach必要なroute両端をFinderが取得できたか
5. Hypothesis Recall十分なsourceから反証可能候補を作れたか
6. Verification独立sourceと実験pairで成立したか

SSA校正ではGate 1が失敗していた。同じ 1.6.10.0 表示でも手元のbytesはSQLi修正済みだった。版ラベルではなくmanifest digestを正本にする。
