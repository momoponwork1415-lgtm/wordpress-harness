# Test patched snapshots through two oracle-separated paths

A patched Snapshot runs through the same oracle-free Campaign path as its vulnerable positive so false promotion is observable, but its Finder never receives the positive Hypothesis. The private grader separately binds the positive Campaign's discovered Causal Identity to the patched Snapshot through the same Verification seam, then Calibration Review requires both the resulting Disproved record and the oracle-free negative Campaign's non-promotion before producing Boundary Pair Evidence.

This separates two facts that one run cannot measure honestly: whether discovery avoids inventing a vulnerability in patched source, and whether the exact discovered cause is absent under equivalent experimental conditions. Passing the positive Hypothesis to the negative Finder would leak the answer; treating “no Hypothesis” as Disproved would confuse exploration miss with causal refutation.
