# Start from public or self-obtainable access

初期CampaignのPermitted Attackerを、unauthenticatedな外部者、または管理者の個別判断なしに通常登録で取得できる最弱権限へ限定する。WordPress Subscriberと、対象構成で同等以下のCustomerまたはplugin固有roleは含むが、Contributor以上、管理者による特別なrole付与、rareな高権限設定を出発点にしない。これによりFocusとPriorityを危険な経路へ集中させ、設定依存性を隠したHypothesisを防ぐ。
