# Use a minimal normal plugin configuration

canonical plugin状態はinstall・activate済みで、公式手順に沿った最小の通常機能を利用できるCanonical Configurationとする。rareな管理者設定、不自然なseed data、既知exploit専用stateを基準へ混ぜない。一般的なoptional featureまたはstateがHypothesisに必要な場合は、差分、設定主体、普及根拠を持つConfiguration Variantとして別Experimentへ固定する。
