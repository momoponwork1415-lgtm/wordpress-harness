# Reuse only target-bound verified route fragments

同じTarget Snapshot内で複数Hypothesisが共有する、連続したobserved Evidence Routeの部分を`Route Fragment`としてResearch Ledgerから参照可能にする。Fragmentはsource range、Target Snapshot digest、関係するExperiment evidence、schema version、作成判断を固定し、Discoveryが同じregistration、guard、state transition、sink等を再調査する費用を減らす。

Route FragmentはFinding、Lesson、Rule、terminal impactの証明ではない。別Hypothesisへ組み込む時は新しいattacker premise、接続edge、downstream impactを個別に仮説化し、VerifierはFragmentを権威として信頼せずTarget Snapshotから再導出する。複数Fragmentを接続しただけでFindingへ昇格させない。

初期FragmentはTarget Snapshotに拘束する。別pluginまたは別versionへ再利用する場合は、構造的類似をLesson ProposalまたはRule Proposalとしてbenchmark gateへ送り、元Fragmentのobserved stateを移植しない。negative evidenceはFragmentにせずClosure RecordとDisproved outcomeに残す。
