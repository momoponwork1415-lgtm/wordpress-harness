# Keep Discovery high-recall

Discoveryは、routeの到達性またはexploitabilityを完全には証明していないspeculativeなSource-bound Hypothesisを受理する。必須条件はPermitted Attacker、security property、実在sourceへ結び付いたhop、unknown、falsifier、次のExperimentであり、自由な疑念だけは受理しない。厳しい成立判定をDiscoveryへ前倒しせず、独立Verificationが反証と実証を所有する。
