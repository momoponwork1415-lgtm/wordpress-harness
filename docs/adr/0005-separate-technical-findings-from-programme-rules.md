# Separate technical Findings from programme rules

DiscoveryとVerificationは、現在のWordfence報奨表ではなく、許可されたattacker premiseから実運用のsecurity propertyが破壊されるかを判断する。programme固有の受付class、version条件、severity threshold、報奨条件はFinding確定後の別判断とする。外部規約の変更で同じ脆弱性の技術的真偽や探索能力が変わることを防ぎつつ、Campaign内ではconcrete impactの大きいHypothesisを優先する。
