# Support manually imported premium plugins

WordPress.org配布pluginはAcquisition adapterがversionとdigestを固定して取得でき、premium pluginはoperatorが正規入手したlocal sourceの手動importだけを受け付ける。harnessがvendor accountのlogin、purchase、license activation、credential保存、downloadを自動化すると、Target acquisitionとsecret・外部取引の責務が混ざるため行わない。どちらの経路もprovenanceとsource digestを持つ同じoracle-free Target Intake Packetへ正規化する。
