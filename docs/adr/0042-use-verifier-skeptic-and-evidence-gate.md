# Use Verifier, Skeptic, and a deterministic evidence gate

通常のFinding昇格経路を、Verifierによる独立再導出とExperiment、別contextのSkepticによる反証監査、deterministic evidence gateの順とする。SkepticはHypothesis、Verification Record、raw evidence referenceだけを受け、DiscoveryまたはVerifier conversationを読まない。VerifierとSkepticが争う場合だけ第二Verifierへ送る。多数決をFinding条件にせず、WitnessとCausal Controlの機械的成立を最終gateとする。
