# Separate Finding from Human Confirmation

独立VerificationがWitnessとCausal Controlを満たした時点をFindingとし、人間による再現確認はHuman Confirmationという後続状態に分ける。harnessのprecision、cost、timeを人間作業から独立に評価できるようにするためである。ただし外部報告、programme submission、vendor contactにはHuman Confirmationを必須とし、AI確定だけでrepository外へFindingを送らない。
