# Build the Surface Map in two layers

Surface Mapは、WordPress hook、REST route、AJAX action、callback、guard、source、storage、sinkを再現可能に列挙するdeterministic inventoryと、それらの関係、trust transition、欠落、動的dispatchを解釈するLLM synthesisの二層で作る。通常Campaignでは人間承認を状態遷移の必須条件にせず、両層の不一致またはpolicy異常をBlockedとして人間へ上げる。人間gateはscope/policy変更と外部報告に残す。
