# Prioritize targets by non-oracle research value

Target SelectionはWordfence programme対象内を外部提出価値のため優先するが、programme適格性を技術的Researchのhard gateにせず、対象外でも価値が高いpluginを調査専用候補として選べる。主要な選定要素は潜在impact、Permitted Attackerから到達し得る攻撃面、利用規模、現行安定版と更新状況、取得可能性とし、報奨金額とmodel confidenceは使わない。

既知脆弱性履歴は初期選定の主要因にせず、非oracleな基準だけで実戦運用した後に必要性を再評価する。導入する場合もCVE、advisory、vulnerability class、affected version、symbol、payload、patchを除いた件数または密度の集計だけを低比重で使い、元のOracle Fact、集計値、oracle由来の選定理由をTarget Intake PacketまたはResearchへ渡さない。
